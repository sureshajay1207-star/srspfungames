# SRSP / SRDP Games

# 🎮 Private Game Night (Dual Mode)

A collection of **consent-first, same-room party games** designed to break awkwardness, build connection, and gradually increase playful tension.

**Now with two modes in every game:**

- **SRSP** – Same Room Same Partner (original style – no swapping)
- **SRDP** – Same Room Different Partner (cross-partner actions allowed while staying in the same room)

These games are built as **mobile-friendly HTML pages** and can be hosted easily using **GitHub Pages**.

---

## 🔒 Core Rules (Apply to All Games)

Before starting any game, all participants should agree to:

- Same room only  
- Consent is mandatory at all times  
- Anyone may skip, pause, or stop at any moment  
- No photos or recordings unless everyone explicitly agrees  

**Mode-specific rules:**

### SRSP Mode
- Same partner only  
- ❌ No swap / no soft-swap  

### SRDP Mode
- Different partner actions are allowed  
- Soft-swap and full physical interaction with the other couple’s partners are permitted  
- Still same-room only  

These games are about **fun, trust, and connection**, not pressure.

## 1️⃣ Truth or Dare Ladder

📄 **File:** `Truthdare.html`

### How It Works
- Choose **Mode** first: SRSP or SRDP
- Choose Mood: Casual → Hot → Wild → Extreme
- Add participants **with gender (Male / Female)**
- Random player is selected each turn
- They choose Truth or Dare
- Prompt is pulled from the correct mode + mood + gender bank
- Scoreboard tracks Truth / Dare / Total

---

## 2️⃣ Naughty Dice (Desire Dice)

📄 **File:** `dice.html`

### How It Works
- Choose **Mode** first: SRSP or SRDP
- Choose Mood: Casual → Hot → Wild
- Add participants + gender
- Player rolls Action + Place dice
- In **SRDP** mode the target is gender-aware (male → other woman, female → other man)
- Perform the action for an agreed duration (15–40 seconds recommended)

---

## 3️⃣ Secret Challenge Cards

📄 **File:** `secret.html`

### How It Works
- Choose **Mode** first: SRSP or SRDP
- Choose Level: Casual → Hot → Spicy → Wild
- Only the selected player sees the secret challenge
- Challenge can be completed anytime during the round
- In **SRDP** mode challenges are gender-aware and can involve the other couple

---

## 🚀 Recommended Play Order

1. Start with **Truth or Dare** (Casual or Hot) in **SRSP** mode
2. Move to **Naughty Dice**
3. Add **Secret Challenge Cards** for suspense
4. Only switch to **SRDP** mode when the whole group is comfortable and has explicitly agreed
